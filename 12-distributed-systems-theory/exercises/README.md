# 第12回 演習

すべて Go(標準ライブラリのみ)。5本は、1つのモジュール(`ex12ds`)にまとめてある。macOS(Apple Silicon)で動作を確認した。**Linux での実行は未確認**。

```bash
cd 12-distributed-systems-theory/exercises
go run ./ex1_logical_clocks
go run ./ex2_physical_time
go run ./ex3_failure_detector
go run ./ex4_consistency
go run ./ex5_partition
```

| 演習 | 実体 |
|---|---|
| ex1 | シミュレーション。Lamport 時計とベクタークロックを、因果関係の「正解」(推移閉包)と比べる |
| ex2 | シミュレーション(確率モデル)。LWW、HLC、TrueTime 風のコミット待ち |
| ex3 | シミュレーション。ハートビートの遅延(裾が重い)と、固定のタイムアウト、φ 検出器 |

| ex5 | シミュレーション。ネットワーク分断の間の、CP と AP |

**実際のネットワーク、実際のデータベースは、使っていない**。数値は、モデルの結果であり、傾向を見るもの。

## 進め方

第1〜11回と同じ。実行前に予想を書き、実行して比べ、外れたら理由を調べる。

**注意**: ex3 は、36 万個のハートビートを、φ 検出器で、何度も走査する(数秒かかる)。ex4 は、4,000 個の履歴を、6 つの設定、2 つの条件で、検査する(数十秒かかることがある)。

## 演習1: 論理時計

[ex1_logical_clocks/](ex1_logical_clocks/)

**課題**

1. 「a → b ならば L(a) < L(b)」の違反が 0 件であることを、確かめよ。**逆**(L(a) < L(b) ならば、a → b)の違反が、どれくらいあるか。
2. プロセス数を 3、5、10、20 と変えて、**並行な対の割合**と、**L の順序のうち、実は並行な割合**が、どう変わるか、予想して、確かめよ。
3. ベクタークロックの**切り詰め**(古い成分を捨てる)を、実装し、**誤判定**がどれだけ出るかを、測れ。
4. **発展**: イベントの種類(送信の割合)を変えて、結果が、どう変わるか。

## 演習2: 物理時計と、その対処

[ex2_physical_time/](ex2_physical_time/)

**課題**

1. LWW で、書き込みが逆転する確率の表(A)を、σ と Δ の、解析的な式(2 つの正規分布の差)で、予想し、実測と比べよ。
2. **HLC の c(論理カウンタ)が、増え続ける**状況(物理時計が、ほとんど進まないのに、大量のイベント)を、作り、c の大きさを、観察せよ。
3. C は、ほぼ自明なモデルである。**ε の保証が、破れる**(時計が、ε を超えて、ずれる)ようにして、コミット待ちでも、逆転が、起きることを、確かめよ。
4. **発展**: 時計のオフセットを、時間と共に**ドリフト**するモデルに、変えよ。

## 演習3: 故障検出

[ex3_failure_detector/](ex3_failure_detector/)

**課題**

1. 固定のタイムアウトの、誤検出と、検出時間の関係を、予想し、確かめよ。
2. φ 検出器が、固定のタイムアウトに、勝てなかった理由の**仮説**(裾が重い)を、**検証**せよ。遅延の分布を、**正規分布に近い**ものに変えて、φ 検出器が、勝つかを、確かめよ。
3. 遅延の**平均が、時間と共に変わる**(例: 夜は 5 ms、昼は 50 ms)モデルで、固定と φ を、比べよ。φ の、本来の利点が、現れるか。
4. **発展**: 停止が、**相関**する(連続して起きる)場合は、どうなるか。

## 演習4: 一貫性と、線形化可能性

[ex4_consistency/](ex4_consistency/)

**課題**

1. R、W の組と、R + W > N かどうかで、**線形化できない履歴の割合**を、予想し、確かめよ。
2. **R = 1、W = 3 が崩れる理由**(§6.3)を、**個別の履歴**を、取り出して(違反した履歴を、印字して)、確認せよ。
3. R = 2、W = 2 の、0.4% の違反の原因を、同様に、**個別の履歴**で、確認せよ。
4. **読みの修復**(読んだ後、古いレプリカに、新しい値を、書き戻す)を、追加して、違反が、どれだけ減るかを、測れ。
5. **発展**: バージョンの割り当てを、**コーディネータごとの、独立なカウンタ**(Lamport 時計)に、変えて、結果がどう変わるか。

## 演習5: ネットワーク分断

[ex5_partition/](ex5_partition/)

**課題**

1. CP と AP の、分断中の成功率と、AP の競合の数を、予想し、確かめよ。
2. 乱数の種を、変えて、競合の数が、どれくらいばらつくか、調べよ(本文では、1 つの種のみ)。
3. AP の、競合を保持する方式に、**マージの関数**(例: 値の和集合)を、追加し、**失われる書き込みが 0** になることを、確かめよ。
4. 分断の長さと、書き込みの頻度に対して、競合の数が、どう変わるか。**発展**: 分断が、{2, 2, 1} の 3 つに、分かれたとき、CP の成功率は。
