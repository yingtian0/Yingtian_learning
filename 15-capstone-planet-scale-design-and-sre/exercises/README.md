## 進め方

第1〜14回と同じ。実行前に予想を書き、実行して比べ、外れたら理由を調べる。

**注意**: ex2 は、200 万リクエストを、7 つの使用率 × 3 つの分布で、走らせる(十数秒)。他は、数秒。

## 演習1: 遅延の裾

[ex1_tail_at_scale/](ex1_tail_at_scale/)

**課題**

1. ファンアウト N と、遅いリクエストの割合を、**理論値 1 − 0.99^N** と、比べよ。N = 1,000 で、100%、になる理由は。
2. ヘッジの待ち時間 h を、変えて、**追加の負荷と、中央値、p99、p99.9** を、予想し、確かめよ。**最適な h**は、あるか。
3. **p99 が、h について、単調でない**(§10 の 1)ことを、**検証**せよ: 標本の数を増やして、p99 の揺れが、小さくなるか。**「両方のコピーが、停止に当たる確率」**から、p99 の位置を、**解析的に**、予測せよ。
4. **遅さの原因が、リクエストの重さ**の場合(C)を、**一部だけ**重い(ヘッジが、一部のサブリクエストにだけ効く)モデルに、拡張せよ。
5. **発展**: **タイド・リクエスト**(最初から、2 台に送り、先に来た方を採る)を、実装し、**ヘッジ**と、比べよ(追加の負荷と、裾)。

## 演習2: 待ち行列

[ex2_queueing/](ex2_queueing/)

**課題**

1. 使用率と、平均の滞在時間が、M/M/1 の理論値 1 / (1 − ρ) と、一致することを、確かめよ。
2. 処理時間の分布(指数、一定、裾の重い)で、**p99** が、どう違うかを、**ポラツェク・ヒンチンの公式**(M/G/1 の、平均の待ち時間 ∝ (1 + 変動係数²) / 2)で、説明せよ。
3. **サーバーを 2 台**(共通の待ち行列)にして、同じ使用率で、遅延が、どう変わるかを、測れ(M/M/2)。**1 つの速いサーバー**と、**2 つの、半分の速さのサーバー**を、比べよ。
4. **p99 ≤ 10(平均の処理時間の 10 倍)**を、満たす、**最大の使用率**を、分布ごとに、見つけよ。
5. **発展**: 処理時間が、**使用率とともに増える**(競合による)モデルで、**崩壊する使用率**を、見つけよ。

## 演習3: 再試行の嵐

[ex3_retry_storm/](ex3_retry_storm/)

**課題**

1. 5 つの方針で、**きっかけが消えた後の、回復**を、予想し、確かめよ。
2. **指数バックオフ + ジッターだけでは、回復しなかった**理由を、考えよ。**バックオフの、待ち時間の上限**、**再試行の回数**、**タイムアウト**を、変えて、**回復する条件**を、探せ(§10 の 2)。
3. **サーバーの処理順**を、**後入れ先出し(LIFO)**に変えて、方針 2 が、回復するかを、確かめよ。
4. **きっかけの長さ**(5 秒、1 秒、0.2 秒)と、**使用率**(60%、80%、95%)を変えて、**準安定な状態に、陥る境界**を、見つけよ。
5. **キャッシュの、コールドスタート**による、準安定な障害(キャッシュが空 → DB に、全てが行く → DB が遅い → キャッシュが埋まらない)を、**別のモデルとして**、作れ。

## 演習4: 過負荷の制御

[ex4_overload_control/](ex4_overload_control/)

**課題**

1. 到着率と、方針ごとの、**goodput、p99、重要なリクエストの成功率**を、予想し、確かめよ。
2. 待ち行列の上限(100)と、待ち時間の上限(100 ms)を、**変えて**、goodput と、遅延の、**トレードオフ**を、調べよ。
3. **重要なリクエストの割合**を、20% から、50%、80% に変えて、**優先度(E)が、重要なものを、守れなくなる**境界を、確かめよ。
4. **時間刻みを、1 ms に、細かくして**、遅延の分布が、どう変わるか、調べよ(§10 の 3)。
5. **サーキットブレーカー**を、クライアント側に、実装し、**下流の障害**のとき、**再試行の嵐を、抑えられる**ことを、確かめよ(演習3 と組み合わせる)。

## 演習5: SLO と警報

[ex5_slo_and_burn_rate/](ex5_slo_and_burn_rate/)

**課題**

1. 可用性の合成(A)の表を、**手計算**で、確かめよ。**共通の原因の割合 c** を、変えて、**2 コピーの可用性**を、計算せよ。
2. 4 つの警報の方針の、**検出時間、見逃し、不要な警報**を、予想し、確かめよ(B)。
3. **ゆっくりした劣化のバーンレートを、5 倍、8 倍、12 倍**に、変えて、方針 4 の、検出と見逃しを、調べよ(§10 の 5)。
4. **チケットレベルの警報**(バーンレート 1 を、3 日の窓と、6 時間の窓で)を、方針 4 に、追加し、5 倍の劣化を、検出できるかを、確かめよ。
5. **「見逃し」の数え方**(§10 の 6)を、**発火中の警報の更新**を、扱う、より現実的な方法に、変えよ。結果は、どう変わるか。
6. **発展**: **自分が、運用しているサービス**(または、想像上のサービス)の、**SLO**を、定義し、**警報の設計**を、書け。
